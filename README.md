# Account — модель банковского счёта

## Возможности

- ✅ Создание счёта с проверкой корректности начального баланса
- ✅ Пополнение счёта (`deposit`) с валидацией суммы
- ✅ Установка кредитного лимита для счёта (`credits`) с валидацией суммы
- ✅ Снятие средств (`withdraw`) с проверкой достаточности баланса
- ✅ Полная история операций с датой, временем, суммой, балансом после операции и статусом
- ✅ Фиксация **неудачных** попыток операций (например, при недостатке средств)
- ✅ Аналитика по истории: количество успешных/неуспешных операций, суммы пополнений и снятий
- ✅ Наглядный вывод истории в консоль

## Требования

- Python **3.7+** (используется только стандартная библиотека — модуль `datetime`)
- Никаких внешних зависимостей
