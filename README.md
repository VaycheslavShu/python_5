# Банковский счёт — модель на Python

Проект моделирует поведение банковского счёта с базовыми операциями
(пополнение и снятие), детальным журналом действий и аналитикой по истории.
Включает два класса: `Account` (обычный счёт) и `CreditAccount`
(кредитный счёт с лимитом), а также интерактивный скрипт `main.py`.

## Возможности

### Account (обычный счёт)

- ✅ Создание счёта с проверкой корректности начального баланса
- ✅ Пополнение счёта (`deposit`) с валидацией суммы
- ✅ Снятие средств (`withdraw`) с проверкой достаточности баланса
- ✅ Полная история операций: дата, время, сумма, баланс после операции, статус
- ✅ Фиксация неудачных попыток операций (недостаток средств, неверная сумма)
- ✅ Аналитика: количество успешных/неуспешных операций, суммы пополнений и снятий
- ✅ Наглядный вывод истории в консоль

### CreditAccount (кредитный счёт)

- ✅ Наследует всю функциональность `Account`
- ✅ Кредитный лимит (`credit_limit`) — баланс может быть отрицательным, но не ниже `-credit_limit`
- ✅ Доступная сумма: `get_available_credit()` → `баланс + кредитный лимит`
- ✅ Снятие средств с учётом кредитной линии
- ✅ Флаг `credit_used` в каждой операции — показывает, использовались ли кредитные средства
- ✅ Расширенная статистика: лимит, доступный кредит, использованный кредит
- ✅ Индикация `[кредит]` при выводе истории

## Быстрый старт

Запуск интерактивного скрипта:

```bash
python main.py
```

Скрипт запрашивает:
1. Имя владельца счёта
2. Начальную сумму
3. Тип счёта (`депозит` или `кредитный`)
4. Для кредитного — кредитный лимит

Затем выполняет демонстрационные операции и выводит историю и статистику.

Использование из кода:

```python
from account import Account
from creditaccount import CreditAccount

# Обычный счёт
acc = Account("Иван Иванов", 100)
acc.deposit(50)       # True
acc.withdraw(30)      # True
acc.withdraw(500)     # False — недостаточно средств
print(acc.get_balance())  # 120.0

# Кредитный счёт
cred = CreditAccount("Мария", balance=100, credit_limit=500)
cred.withdraw(300)    # True — баланс уходит в минус (-200)
cred.withdraw(400)    # False — превышен лимит (доступно 300)
print(cred.get_available_credit())  # 300.0
```

## Класс Account

### Конструктор

```python
Account(account_holder: str, balance: float = 0)
```

| Параметр | Описание |
|----------|----------|
| `account_holder` | ФИО владельца счёта |
| `balance` | Начальный баланс (должен быть ≥ 0) |

При отрицательном балансе бросается `ValueError`.

### Атрибуты

| Атрибут | Тип | Описание |
|---------|-----|----------|
| `holder` | `str` | Имя владельца (публичный) |
| `_balance` | `float` | Текущий баланс (приватный) |
| `operations_history` | `list[dict]` | История операций |

### Методы

| Метод | Описание |
|-------|----------|
| `deposit(amount) -> bool` | Пополнение счёта. `True` при успехе |
| `withdraw(amount) -> bool` | Снятие средств. `True` при успехе |
| `get_balance() -> float` | Текущий баланс |
| `get_history() -> list[dict]` | Копия истории операций |
| `get_statistics() -> dict` | Сводная статистика |
| `print_history()` | Вывод истории в консоль |

## Класс CreditAccount

### Конструктор

```python
CreditAccount(account_holder: str, balance: float = 0, credit_limit: float = 0)
```

| Параметр | Описание |
|----------|----------|
| `account_holder` | ФИО владельца |
| `balance` | Начальный баланс (может быть отрицательным, но ≥ `-credit_limit`) |
| `credit_limit` | Максимальный кредитный лимит (≥ 0) |

### Дополнительные методы

| Метод | Описание |
|-------|----------|
| `get_available_credit() -> float` | Доступная сумма: `баланс + кредитный лимит` |

### Переопределённые методы

| Метод | Отличие от родителя |
|-------|---------------------|
| `withdraw(amount)` | Проверяет не только баланс, но и `баланс + кредитный лимит` |
| `_record_operation(...)` | Добавляет поле `credit_used: bool` в каждую запись |
| `print_history()` | Показывает флаг `[кредит]` и текущий лимит |
| `get_statistics()` | Добавляет поля `credit_limit`, `available_credit`, `credit_in_use` |

## Формат записи операции

Каждая операция хранится как словарь:

```python
{
    "type": "deposit" | "withdraw",
    "amount": 50.0,
    "datetime": datetime(2026, 11, 3, 14, 30, 0),
    "balance_after": 150.0,
    "status": "success" | "fail",
}
```

Для `CreditAccount` добавляется поле:

```python
{
    ...
    "credit_used": True,  # True если успешное снятие привело к отрицательному балансу
}
```

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Отрицательный начальный баланс (`Account`) | `ValueError` при создании |
| Баланс ниже `-credit_limit` (`CreditAccount`) | `ValueError` при создании |
| Не числовая сумма (строка, `None`, `bool`) | `TypeError` → операция фиксируется как `fail`, метод возвращает `False` |
| Отрицательная или нулевая сумма | `ValueError` → операция фиксируется как `fail`, метод возвращает `False` |
| Недостаточно средств (`Account`) | Операция `fail`, баланс не меняется |
| Превышение кредитного лимита (`CreditAccount`) | Операция `fail`, баланс не меняется |
